# About [Name]: start here

This folder tells Claude (or anyone helping me) who I am, how I think, how I talk and how I write, so I don't have to brief it again every time.

**Rule for Claude:** read this folder before writing anything in my name or making anything about me. Read 01 to 05 every time; read 06 only to see what's still open.

| File | Use it for |
| --- | --- |
| 01 Who I Am | My story, values, drives, goals |
| 02 How I Think and Work | How I decide and work, red lines |
| 03 How I Write | My voice and writing rules |
| 04 How I Talk | How I speak, and how Claude should talk to me |
| 05 My Career Story | Public story, interview lines, PRIVATE notes |
| 06 Questions | What's still open |

## Hard rules

1. Facts only from me. Never invent; ask instead.
2. Anything marked PRIVATE follows its own usage rule and never appears in public writing otherwise.
3. Sound like me, not like an AI.
4. When I correct something, update this folder.
